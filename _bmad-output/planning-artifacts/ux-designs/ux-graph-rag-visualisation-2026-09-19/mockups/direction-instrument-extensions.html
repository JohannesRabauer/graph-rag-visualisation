Three things to decide before Epic 7 & 8 lock in

Working sketches, not final chrome — same tokens as the shipped app (paper / panel / ink / line / accent / global). Pick a direction in each section; nothing here is load-bearing yet.

01

DRIFT's third mode color

The existing rule bans a third saturated mode hue — you chose to break it, so DRIFT needs a real color of its own. All three candidates below avoid the palette already spoken for: accent blue, global teal, active warm-orange, and all five Community hull tints.

Worth knowing

Violet sits closest to Community-4's pale purple hull tint — fine as a saturated toggle/answer-tag color, but if DRIFT ever gets its own node-highlight ring on the graph canvas (like Local's accent ring), it'll want to stay clearly more saturated than that hull, the same way active-orange already out-saturates Community-1's orange.

Rose has zero collision anywhere in the current palette — cleanest pick if you want DRIFT visually unmistakable at a glance.

Bronze reads calmer/earthier, furthest in tone from both existing mode colors, but is the closest in family to Community-5's gold.

03

Vector Space — the new comparison view

A "Compare" action on any answer (on-demand, not automatic) opens a second tab next to Knowledge Graph. Chunks appear as points in projected embedding space; asking a question drops the query in live and lights up its nearest neighbors with their similarity scores — the literal picture of "what got vectorized."

Worth knowing

The query dot reuses active-orange (today's "current step" color) since it means the same thing here: "this is the live, happening-right-now thing." Hit chunks use accent-blue rings rather than a new hue — deliberately, so a viewer doesn't have to learn a fourth color meaning just for this one view.

Open question this sketch doesn't answer yet: does the 2D projection recompute per corpus (so layout is stable across questions), or does it visually "settle" once at ingestion time? Worth pinning down before Story 8.4 gets written.
