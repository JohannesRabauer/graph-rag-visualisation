The drift tree

During replay of a Drift answer, a small tree at the bottom of the canvas shows the community branches, their sub-questions and the final synthesis.

Overview

See Drift Search for how the branches arise.

The idea

Drift is iterative and branching, so a flat list of steps hides its structure. A tree shows which follow-up came from which context.

In this demo

The tree is built in the browser from the trace: each SUB_QUESTION_SPAWNED step opens a branch, and the first SYNTHESIS step closes them, exactly the grouping AnswerDriftSearch writes. Stepping through the replay highlights the branch being played. It only appears for traces that contain sub-questions.

Simplifications

  • The tree comes from the trace; it is not a separate model of the reasoning.
