The graph

Communities

A community is a cluster of entities that are linked to each other. The shaded regions and the legend chips at the bottom left show them; Global and Drift Search read their summaries.

Overview

Click a legend chip to focus its community.

The idea

GraphRAG clusters the entity graph (the original work uses the Leiden algorithm) and has an LLM write a report for each cluster. Those reports let global questions be answered without reading every chunk.

In this demo

DetectCommunities is much simpler than Leiden: it takes the connected components of the graph, so two entities share a community only if a chain of relationships joins them. Each gets an id such as community-1 and a summary. With an API key LlmPort writes the summary; otherwise it is the template "This community centers on" followed by up to four entity names. The result is persisted and announced as community-detected events.

Readers of communities: Global Search and Drift Search.

Simplifications

  • Connected components, not modularity-based clustering: one bridge relationship merges two clusters, and there is no hierarchy of levels.
  • Detection always runs; the formation view is visual only.
