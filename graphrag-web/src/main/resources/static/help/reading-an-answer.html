Answers

Reading an answer

Each answer carries a tag naming the mode that produced it, the answer text with its [n] source markers, a Sources list, a link to replay its trace, and a button to compare it with plain vector search.

Overview

Learn more: trace replay, vector versus GraphRAG, and the three modes compared.

The idea

An answer is only trustworthy if you can see where it came from. GraphRAG retrieval is a path through a graph, so that path can be shown, unlike an opaque similarity score.

In this demo

The message is built from the query response: answer, the mode, a traceId and a step count. The trace is a RetrievalTrace made of RetrievalStep entries and kept in RetrievalTraceStore. If the mode found nothing, the message shows the reason instead of an answer, and the replay link says "0 steps". Answers from a Vector comparison have no Compare button of their own.

Sources and passages

A Local, Global or DRIFT answer written by the model cites the passages it used. Each [n] in the text is a small button that points to source n; a grouped marker such as [1, 2] gives one button per number. Under the answer, the Sources list shows one row per source: its number, the document it came from and a short excerpt.

Click a marker or a Sources row to open that passage's full text in a panel under the answer, and click it again to close the panel. The text comes from GET /api/corpora/{corpusId}/text-units/{textUnitId}, the same endpoint the entity detail panel uses for its source passages. Each passage is fetched once and then reused. If it cannot be loaded, the panel says "Passage not available".

The query response carries the sources as a citations list of Citation entries (text unit id, document name, excerpt). CitationResolver renumbers the markers so [n] always means the n-th entry. A marker with no matching entry stays plain text. Answers without citations, such as the offline demo's templated answers, Vector answers, or a "nothing found" reply, show no markers and no Sources list.

Simplifications

  • Without an OpenAI key (the offline demo, for example) the answer text is templated, so it reads more mechanically than an LLM-written one and carries no citations.
