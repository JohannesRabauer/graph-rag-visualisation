The graph

The knowledge graph

Every circle is an entity the extractor found; every line is a relationship between two of them. Shaded regions group entities into communities.

Overview

Click an entity for its detail panel. The legend and communities, and the entity colours, explain the shading.

The idea

A knowledge graph stores facts as (entity, relationship, entity) triples. GraphRAG builds one from text so that retrieval can follow connections instead of only matching similar passages.

In this demo

The graph is drawn with Cytoscape and grows live as CorpusProgressService events arrive. Entities are Entity records identified by name plus type; relationships are Relationship records with a source, a type and a target. Controls: zoom in, zoom out and fit-to-view, a search box to jump to an entity by name, and a settings menu for display options. The canvas re-fits itself whenever its space changes, for instance when this help pane opens.

The other tab, Compare, appears after you use Compare under an answer; see vector search versus GraphRAG.

Simplifications

  • The layout is only for readability: distances on the canvas carry no meaning.
