Search mode

Global Search

Read every community summary, pick the one that overlaps your question most, and answer from it. Built for broad questions like "what is this corpus about?".

Overview

Each community is one trace step, so the trace lists all communities, not only the winner.

The idea

In canonical GraphRAG, global search maps the question over community reports (LLM-written summaries of graph clusters), asks the model for partial answers, and reduces them into one answer. That lets it answer questions no single entity or chunk contains.

In this demo

AnswerGlobalSearch reads only the communities already persisted by DetectCommunities; it never triggers detection itself. It scores each community summary with KeywordMatcher and the best score wins (ties go to the smaller community id). The answer is "Across the corpus, the strongest signal is that" followed by that summary. If no summary matches, it says so honestly. If the corpus has no communities yet, it returns a no-answer with a reason.

With keyword matching (offline), the trace is one COMMUNITY step per community, in read order. The score is not recorded, which is why the live view below marks the winner by finding its summary in the answer text.

With a real embedding model configured (OPENAI_API_KEY set), Global Search instead records only the three communities whose summaries are closest in meaning to the question, in similarity order, and answers from the first; a corpus without community embeddings, or the offline stub, falls back to the keyword scoring above.

Simplifications

  • Local Search here is not chunk based and not LLM based: no text chunks are retrieved and no model writes the answer.
  • Drift sub-questions and the synthesis are deterministic templates, not model output.
  • When an OPENAI_API_KEY is set, entity extraction and community summaries are the only LLM-generated parts, and entity and community embeddings pick the search starting points by meaning. Without a key (offline), regex extraction and hashed bag-of-words embeddings stand in, and starting points are matched by keywords only.

There is no map or reduce phase: exactly one summary is quoted.
