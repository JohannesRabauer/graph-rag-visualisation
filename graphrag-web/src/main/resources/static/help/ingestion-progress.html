Overview

If the stream drops, a retry button appears. See also the graph overview.

The idea

Building a GraphRAG index is a pipeline: extract entities and relationships, cluster the graph into communities, summarise each community, and (for the vector baseline) embed text chunks. It is slow, which is why showing progress matters.

In this demo

The server announces progress over server-sent events, fanned out by CorpusProgressService: ingestion-started, entity-extracted, relationship-extracted, community-detected, then ingestion-complete (or error). CorpusController emits them as ExtractEntitiesAndRelationships and DetectCommunities persist their results. A small replay buffer means a page that connects late still receives the earlier events.

The states you see are Building, Ready and Failed. A corpus that was still building when the app stopped is marked Failed on the next start by InterruptedCorpusReconciler.
