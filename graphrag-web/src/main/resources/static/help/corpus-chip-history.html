Corpora

Corpus chip and history

The chip names the corpus you are looking at. The history list brings back any corpus you built before, without re-ingesting it.

Overview

"Start over with a new corpus" clears the current view and returns to the upload screen.

The idea

Indexing is the expensive part of GraphRAG, so a real system persists the index and reuses it across sessions.

In this demo

Corpora are stored durably in Neo4j through Neo4jCorpusRegistry, so they survive a restart. Picking one from the list calls the activate endpoint on CorpusController and redraws its graph from the stored data. On page load the most recently activated corpus is restored automatically. The offline demo is not listed.

Retrieval traces are not persisted. They live only in memory (RetrievalTraceStore), so a restart clears them and the live layer of the help articles starts empty again.

Simplifications

  • Switching corpus clears the chat thread and the last-answer memory shown by the help pane.
