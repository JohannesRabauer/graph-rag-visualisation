Getting started

The demo datasets

Two one-click corpora built from the same Sherlock Holmes stories: a live one, and an offline one that makes no API calls.

Overview

Use the live demo to try the search modes; use the offline one to show the graph and ingestion with no network or key.

The idea

A demo dataset removes the "find a corpus" step and gives a presenter a known graph to talk about.

In this demo

DemoDatasetService creates both corpora from the same Sherlock Holmes documents under different names. The live demo builds like an upload. The offline demo (POST /api/corpora/demo-offline, handled by CorpusController) builds the same corpus with deterministic stubs, so it needs no OpenAI key and makes no API calls. It is left out of the corpus history list.

The offline demo does not answer questions: its question box is disabled and the server rejects queries. The note under the box says questions are "pre-recorded", but no recorded answers exist. The live layer of the search articles says the same when the offline demo is active.

Simplifications

  • Offline means "no API calls", not "recorded answers".
  • Stub extraction and hashed bag-of-words embeddings make a rougher graph than a real model would.
