The graph

Entity detail panel

Click any entity on the canvas to open a panel with its name, type, description, source passages, relationships and tags. Close it with the x.

Overview

Relationship rows lead you to the neighbours worth trying in a Local Search; hover a relationship to read its extracted description when one exists.

The idea

Inspecting a node and its edges is the most direct way to check whether the extracted graph matches the source text.

In this demo

This screen builds its graph incrementally from progress events, so the panel lists the relationships it has accumulated for the selected Entity from Relationship events rather than fetching them. Entity descriptions and source passage labels arrive with the graph events; the passage text itself is fetched only when you expand a source row. When you switch corpus, any open panel is closed. The panel sits over the right edge of the canvas; the help pane is a separate column beside it and never overlaps.

Simplifications

  • While a corpus is still building, the list can be incomplete.
