The graph

Entity detail panel

Click any entity on the canvas to open a panel with its name, type, relationships and tags. Close it with the x.

Overview

Relationship rows lead you to the neighbours worth trying in a Local Search.

The idea

Inspecting a node and its edges is the most direct way to check whether the extracted graph matches the source text.

In this demo

This screen builds its graph incrementally from progress events, so the panel lists the relationships it has accumulated for the selected Entity from Relationship events rather than fetching them. When you switch corpus, any open panel is closed. The panel sits over the right edge of the canvas; the help pane is a separate column beside it and never overlaps.

Simplifications

  • While a corpus is still building, the list can be incomplete.
