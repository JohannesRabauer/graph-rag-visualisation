The graph

Entity types and colours

Each entity has a type such as person or place. One switch in the settings menu colours nodes and tags by type, so the same type always has the same colour.

Overview

The settings button is the gear at the top right of the canvas.

The idea

Typed entities let a graph answer structured questions ("which people?") and make a large graph readable at a glance.

In this demo

The type is whatever LlmPort returned for the entity, stored on Entity. The toggle "Color-code entity types" only changes drawing; it does not change the graph or any search. Type colours are deliberately duskier than the pastel community regions so the two colour languages stay distinguishable (see communities). A separate toggle turns the community formation animation on and off. The type is also part of what Local Search scores against, next to the name.

Simplifications

  • Only a handful of type colours exist; more types than that reuse colours.
